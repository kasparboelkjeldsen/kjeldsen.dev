About this blog

Every document type, block, image and paragraph you see here was created by an AI agent talking to Umbraco through the Model Context Protocol. No clicking around the backoffice and no hand-written migrations: just an agent, a set of well-described tools, and a CMS that exposes its Management API through them.

The front page is a block grid. So is every post. Editors can rearrange heroes, text, images and quotes freely, and the templates don't need to change.
