MCP Is the USB-C Port for AI

One plug, every tool: why a boring standard is the most exciting thing to happen to AI assistants.

Photo: Lucian Alexe / Unsplash

Remember the drawer full of chargers? A different cable for every phone, camera and laptop. That is what AI integrations looked like until recently. Every assistant needed its own custom connector for every tool: one plugin format here, a bespoke function-calling schema there, a pile of glue code in between. With M models and N tools you needed M × N integrations, and most of them were never built.

One protocol, both directions

The Model Context Protocol (MCP) is an open standard for connecting AI applications to the systems where data and actions live. A tool exposes itself once, as an MCP server. Any MCP-capable client — a chat app, an IDE, a coding agent — can then discover and use it. M × N becomes M + N.

A server describes three kinds of things:

  • Tools — actions the model can take, each with a JSON schema for its input.

  • Resources — data the model can read, addressed by URI.

  • Prompts — reusable, parameterised templates a user can invoke.

Why this matters

Build once, work everywhere. A vendor ships one MCP server, and it works in every compatible assistant. You don't need a separate plugin for each one.

Discovery is built in. Clients ask a server what it can do at runtime. Nobody hard-codes tool lists, so new capabilities show up without touching the client.

Local by default. A server can run as a plain process on your machine over stdio. Your credentials and data stay where they already are.

The network effect kicks in

Every new MCP server makes every MCP client more useful, and every new client makes every server more valuable. That flywheel is why the ecosystem grew so fast. Databases, ticket trackers, design tools, browsers, and yes, content management systems like Umbraco, can all join the conversation.

USB-C didn't make laptops faster. It made them easier to connect, and that turned out to matter more. MCP does the same for AI: it doesn't make the model smarter, but it gives the model far more to work with.
