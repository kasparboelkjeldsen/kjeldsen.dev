Why MCP Is Awesome: Giving AI Real Hands on Your Systems

September 28, 2026

A protocol, not another chatbot

Most people's first encounter with AI is a chat window. MCP is about everything chat windows don't do: giving a model a structured, permissioned way to call real tools — read a database, create a page, upload a file — and get a real result back, not a guess.

One protocol, every tool

Before MCP, every integration between a model and a piece of software was bespoke: a custom plugin here, a hand-rolled function schema there. MCP standardises the handshake — discovery, authentication, typed calls, structured results — so a server written once works with any MCP-aware client. Build the Umbraco server once; every agent that speaks MCP can manage content through it.

“The best tools don't ask you to describe your problem in English twice — once to a person, once to an API. MCP lets the agent read the same structured contract the humans built the software around.”

— A happy MCP user

It keeps humans in control

Every MCP server defines exactly what it exposes. An Umbraco MCP server can offer document, media and data-type operations without ever handing over a database connection string or a shell. That's a sharper boundary than most 'give the AI admin access' integrations end up with — and it's auditable: every call is a named tool with a schema.
