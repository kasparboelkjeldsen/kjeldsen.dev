MCP Turns Your CMS into Something an AI Can Work In

A CMS has always been a place where humans click through forms. With an MCP server it becomes a place where an assistant can model, create and verify content, with you reviewing the result.

From forms to conversations

Content management has always meant clicking through forms: create a document type, add a property, pick a data type, save, repeat. It works, but it is slow when the task is really just describing what you want.

With the Umbraco MCP server, an assistant can do those steps for you. It can create element types, wire them into a block grid, import media, and publish pages. You describe the site; it does the clicking.

Safe, because it is the same API

The MCP server does not bypass anything. It talks to the same management API the backoffice uses, with the same permissions, validation and audit trail. A change made by an assistant is a change you can see, review and roll back like any other.

Better still, every structural change can be read straight back. Create a document, fetch it again, and confirm the content landed exactly as intended before moving on.

  • Model: document types, element types, data types and templates.
  • Create: documents, media and domains.
  • Verify: read everything back through the same tools.

“You describe the site; the assistant does the clicking, and you review the result.”

— A happy Umbraco editor
