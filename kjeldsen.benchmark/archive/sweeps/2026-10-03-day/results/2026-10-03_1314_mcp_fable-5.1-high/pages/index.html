The MCP Blog

Notes on the Model Context Protocol. Every document type, image and post on this site was created through Umbraco's MCP server, without opening the backoffice.

What this blog is about

The Model Context Protocol (MCP) is an open standard that lets AI assistants talk to tools and data through one shared interface. This small blog exists to show what that looks like in practice: the content model, the media library and the posts below were all built by an agent calling the Umbraco MCP server, step by step.
